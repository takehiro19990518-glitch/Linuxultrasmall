# ライセンス

P3 Linux は多数のオープンソースソフトウェアから構成されています。
各パッケージのライセンスは `packages.csv`（パッケージ名・バージョン・ライセンス・ライセンスファイル）を参照してください。
ライセンス本文は各ソースに含まれています（ソースの入手方法は BUILD.md を参照）。

- P3 Linux 独自部分（`package/p3-desktop`、`board/`、`scripts/` など）：MIT
- ファームウェア（`package/p3-firmware`）：linux-firmware の各ライセンス（再配布可能なもののみ。詳細は linux-firmware の WHENCE）
- Freedoom：BSD-3-Clause
- VL ゴシック：M+ FONTS / BSD-3-Clause
